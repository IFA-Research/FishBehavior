Fish Behavior Classification

Real-Time Classification of Fish Feeding Intensity Using MobileViT and Temporal Models

This project presents a modular pipeline for classifying fish feeding behavior (Strong, Medium, Weak, None) in aquaculture environments. It combines a MobileViT backbone with temporal modules (BiLSTM or Transformer) to process video sequences and estimate feeding intensity efficiently.
